<h4 align="center">
  <strong>A structured journey through Python, data analysis and backend development.</strong>
</h4>

Repositorio donde documento mi aprendizaje en programación, análisis de datos y desarrollo de software mediante ejercicios prácticos y pequeños proyectos.

Tras dedicar varios meses a preparar y obtener el nivel B2 de inglés, he retomado el estudio desde los fundamentos de Python para reforzar la lógica de programación y construir una base sólida antes de avanzar hacia tecnologías más complejas.

El objetivo no es únicamente aprender la sintaxis del lenguaje, sino comprender cómo diseñar soluciones, organizar el código y desarrollar proyectos cada vez más completos.

---

<h2 align="center"> Objetivos del repositorio </h2>

- Consolidar los fundamentos de Python.
- Mejorar la lógica de programación mediante ejercicios prácticos.
- Aplicar buenas prácticas de organización del código.
- Desarrollar pequeños proyectos para integrar los conocimientos adquiridos.
- Evolucionar progresivamente hacia el análisis de datos y el desarrollo de aplicaciones.
