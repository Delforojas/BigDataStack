# Ejercicios de bucles `for`

Este directorio contiene ejercicios desarrollados para practicar el uso del bucle `for` en Python.

## Conceptos trabajados

- Recorrer listas

- Recorrer cadenas de texto

- Contadores

- Acumuladores

- Condicionales dentro de un `for`

- Bucles anidados

- Validación de datos

## Ejercicios

- Tabla de multiplicar

- Contador de vocales

- Adivinar número

- Simulador de ahorro

- Media de notas

- Mini cajero

- Acumulador de gastos

- Validador de contraseña
